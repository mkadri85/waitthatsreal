# Wait, That's Real

Wait, That's Real is an educational short-form video channel. Each video shares one
true but surprising fact from science, space, technology and AI in about 60 seconds.

- YouTube: https://www.youtube.com/@waitthatsreaal
- TikTok: (coming soon)

## About this repository

This repository hosts the public Privacy Policy and Terms of Service for the
Wait, That's Real publishing application. The application uses official platform
APIs (such as the YouTube Data API and the TikTok Content Posting API) to publish
videos to accounts owned and operated by the channel owner.

- [Privacy Policy](PRIVACY.md)
- [Terms of Service](TERMS.md)

The application is operated for a single owner account. It does not offer accounts
to the public and does not collect data from viewers or third parties.
