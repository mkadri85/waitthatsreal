# Privacy Policy

Last updated: 2026-06-10

This Privacy Policy explains how the Wait, That's Real publishing application
(the "Application") handles information. The Application is operated by the owner of
the Wait, That's Real channel (the "Operator") for the sole purpose of creating and
publishing the Operator's own short-form videos.

Contact: engmohamedkadri85@gmail.com

## 1. Scope

The Application is a private, single-owner tool. It is not offered to the public,
it does not create accounts for other users, and it does not collect, process, or
store personal information about video viewers or any third party.

## 2. Information the Application accesses

To publish videos, the Operator authorizes the Application to access the Operator's
own accounts on third-party platforms through their official APIs, for example the
YouTube Data API and the TikTok Content Posting API. The access is limited to:

- OAuth access and refresh tokens issued to the Operator for the Operator's own
  accounts.
- The ability to upload videos and read basic statistics (such as view and like
  counts) for the Operator's own content.

The Application does not request access to private messages, contacts, payment
information, or the data of any other person.

## 3. How the information is used

Authorization tokens are used only to:

- Upload videos created by the Operator to the Operator's own channels.
- Set or update the title, description, tags, and privacy status of those videos.
- Read aggregate performance statistics for the Operator's own videos.

The information is never used for advertising, profiling, or any purpose unrelated
to publishing the Operator's content.

## 4. Storage and security

OAuth tokens are stored securely using Google Cloud Secret Manager with access
restricted to the Operator's own cloud project. Tokens are encrypted at rest and in
transit. They are not sold, rented, or shared with any third party.

## 5. Google API and TikTok API compliance

The Application's use and transfer of information received from Google APIs adheres
to the Google API Services User Data Policy, including the Limited Use requirements.
The Application's use of the TikTok API adheres to the TikTok Developer Terms of
Service and Platform Policies. Data obtained through these APIs is used only to
provide the publishing function described above.

## 6. Data retention and revocation

The Operator may revoke the Application's access at any time:

- For Google and YouTube: https://myaccount.google.com/permissions
- For TikTok: the connected apps settings inside the TikTok account.

Once access is revoked, the stored tokens are no longer valid and are deleted from
Secret Manager.

## 7. Children

The Application is not directed to children and does not knowingly collect any
information from children.

## 8. Changes to this policy

This policy may be updated from time to time. Material changes will be reflected by
updating the "Last updated" date at the top of this document.

## 9. Contact
